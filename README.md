Функциональность:

- При запуске автоматически создаётся таблица **«Гостиница»** (пример конкретной таблицы).
- Поддерживается создание любых других таблиц.
- Для каждой таблицы доступны CRUD-операции:
  -  Добавление записей
  -  Просмотр всех записей
  -  Поиск по фильтру (любое поле)
  -  Обновление записи по ID
  -  Удаление записи по ID
- Возможность переключаться между созданными таблицами.


Использование программы
При запуске программы появляется главное меню (управление таблицами):

=== УПРАВЛЕНИЕ ТАБЛИЦАМИ ===
1. Создать таблицу
2. Выбрать таблицу
0. Выход

После выбора таблицы открывается рабочее меню:

=== Имя_Таблицы ===
1. Добавить запись
2. Все записи
3. Найти
4. Обновить
5. Удалить
6. Сменить таблицу
0. Выход


Как запустить:

1. Откройте терминал (командную строку)
2. Перейдите в корневую папку проекта
3. Выполните команду:
  
   python -m src.db
